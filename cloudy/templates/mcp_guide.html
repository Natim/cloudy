Vos carnets de vol, dans Claude et ChatGPT

Cloudy expose un serveur MCP (Model Context Protocol). Une fois connecté avec votre compte, Claude ou ChatGPT peut lister vos carnets et en lire les statistiques : totaux, évolution dans le temps, valeurs les plus fréquentes et aérodromes.

L'adresse du serveur est {{ request.scheme }}://{{ request.get_host }}/mcp. L'accès se fait avec un jeton personnel, envoyé dans l'en-tête Authorization. Le mot de passe du compte Cloudy ne se colle pas dans l'assistant.

Ce que vous pouvez demander

Quelques questions, une fois le connecteur activé dans la conversation :

« Quels carnets sont sur mon compte, et combien d'heures totalisent-ils cette année ? »

« Quels sont mes aérodromes les plus fréquentés depuis janvier ? »

« Montre l'évolution de mes atterrissages sur les douze derniers mois. »

L'assistant commence par lister les carnets, puis demande les noms de totaux disponibles avant de calculer. Les dates acceptées sont au format AAAA-MM-JJ ou JJ/MM/AAAA.

1. Obtenir un jeton

Le jeton s'obtient avec l'e-mail et le mot de passe du compte Cloudy. Il reste valable 30 jours (la réponse indique la durée exacte dans expires_in, en secondes). Renouvelez-le de la même façon quand il expire. 

curl -s -X POST {{ request.scheme }}://{{ request.get_host }}/api/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{"email":"vous@exemple.fr","password":"votre-mot-de-passe"}'

La réponse contient le jeton à recopier :

{
  "access_token": "eyJ…",
  "token_type": "bearer",
  "expires_in": 2592000,
  "user_id": 123
}

Dans Claude ou ChatGPT, la valeur d'en-tête est le mot Bearer, une espace, puis access_token. Exemple : Bearer eyJ…. Gardez ce jeton pour vous : il donne accès en lecture aux carnets du compte.

2. Connecter Claude

Les connecteurs distants sont disponibles sur claude.ai, Claude Desktop et Cowork (forfaits Free, Pro, Max, Team et Enterprise ; un seul connecteur personnalisé en Free). Claude appelle Cloudy depuis les serveurs d'Anthropic : le serveur doit être joignable sur Internet, ce qui est le cas de Cloudy.

Compte Pro ou Max

  1. Ouvrez Personnaliser → Connecteurs (Customize → Connectors).
  2. Cliquez + Ajouter, puis Ajouter un connecteur personnalisé.
  3. Nom : Cloudy. Adresse : {{ request.scheme }}://{{ request.get_host }}/mcp. Continuez.
  4. Authentification : Aucune connexion (No sign-in).
  5. En-têtes de requête (Request headers) : nom authorization, valeur Bearer suivi de votre jeton. Marquez l'en-tête comme requis.
  6. Validez avec Ajouter.

Forfait Team ou Enterprise

Un propriétaire de l'organisation ajoute d'abord le connecteur dans Paramètres de l'organisation → Connecteurs → Ajouter → Personnalisé → Web, avec les mêmes nom, adresse et en-tête. Chaque membre le retrouve ensuite dans Personnaliser → Connecteurs et clique sur Connecter. Le jeton est commun à toutes les personnes qui utilisent ce connecteur : choisissez un compte Cloudy dont les carnets peuvent être lus par ce groupe, ou un compte Claude personnel.

La saisie d'en-têtes est encore en bêta chez Anthropic. Si la section n'apparaît pas, utilisez la configuration locale de Claude Desktop ci-dessous.

Dans une conversation

Cliquez sur + en bas à gauche du message, puis Connecteurs, et activez Cloudy. Vous pouvez ensuite poser une question sur vos vols. Pour retirer l'accès, supprimez le connecteur dans les mêmes réglages : le jeton n'est plus envoyé.

Claude Desktop, en local

Cette configuration envoie le jeton depuis votre ordinateur. Fichier selon le système : ~/Library/Application Support/Claude/claude_desktop_config.json (macOS), %APPDATA%\Claude\claude_desktop_config.json (Windows), ~/.config/Claude/claude_desktop_config.json (Linux). Node.js doit être installé. Redémarrez Claude Desktop après l'enregistrement. 

{
  "mcpServers": {
    "cloudy": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "{{ request.scheme }}://{{ request.get_host }}/mcp",
        "--header",
        "Authorization: Bearer VOTRE_JETON"
      ]
    }
  }
}

3. Connecter ChatGPT

La connexion se fait sur ChatGPT web. La création d'un serveur MCP personnalisé est ouverte aux espaces Business, Enterprise et Edu (administrateurs, et membres autorisés en Enterprise). Les comptes Pro peuvent brancher un serveur MCP pour des actions de lecture, ce qui correspond aux outils Cloudy.

  1. Ouvrez Plugins.
  2. Cliquez sur +, puis Ajouter un serveur MCP personnalisé.
  3. Nom : Cloudy. Description libre, par exemple « Statistiques de mes carnets de vol Cloudy ».
  4. Adresse du serveur : {{ request.scheme }}://{{ request.get_host }}/mcp.
  5. Authentification : si un champ d'en-tête ou de clé API est proposé, nom authorization, valeur Bearer suivi de votre jeton.
  6. Cochez l'avertissement, puis Créer comme plugin.
  7. Installez le plugin. Dans une nouvelle conversation, tapez @ et choisissez Cloudy.

Sur les écrans plus anciens, le même ajout passe par le mode développeur, puis Applications → Créer, avec la même adresse. ChatGPT propose aujourd'hui OAuth, ou une connexion sans authentification. Cloudy attend le jeton Bearer décrit plus haut : sans champ pour cet en-tête, la connexion est refusée. Le mot de passe du compte ne remplace pas le jeton.

Les outils

Six outils, tous en lecture. Ils ne créent, ne modifient et ne suppriment aucun vol. Chaque appel ne voit que les carnets du compte auquel appartient le jeton.

list_logbooks
Liste les carnets actifs du pilote : identifiant, nom, catégorie.
describe_totals
Donne les noms de totaux disponibles pour un carnet (heures, atterrissages, etc.).
get_totals
Calcule un ou plusieurs de ces totaux, sur une période et avec des filtres éventuels.
time_series
Découpe un total dans le temps, comme les graphiques du site.
top_values
Classe les valeurs les plus fréquentes d'un total regroupé (appareil, fonction, etc.).
airports
Compte les passages par aérodrome et renvoie les coordonnées pour une carte.

Ce que l'assistant voit

Le jeton voyage dans l'en-tête Authorization, jamais dans le texte de la question. Claude et ChatGPT reçoivent ensuite les réponses des outils : totaux, séries et aérodromes de vos carnets. Ils ne reçoivent pas le mot de passe du compte.

Pour couper l'accès, retirez le connecteur dans Claude ou le plugin dans ChatGPT. Le jeton déjà émis reste valable jusqu'à son expiration : évitez de le laisser dans un fichier de configuration partagé.

Une question sur la connexion ? Écrivez à support@cloudy.fr.

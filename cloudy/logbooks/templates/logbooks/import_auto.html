Mode d'emploi

1 - Téléchargez le format d'import Cloudy.
2 - Remplissez ce fichier avec vos informations de vol et selon les colonnes bien définies.
3 - Lors de l'enregistrement, vérifiez les points suivants :
- Fichier au format CSV. (extension .csv)
- Encodage de caractères : UTF-8
- Option de séparateur : Point-virgule (;)
- Séparateur de texte : Guillemet (")

Libre Office/Open Office vous demande ces informations lors de l'ouverture d'un fichier csv.
Pour Excel, version supérieure à 2011, il faut importer le fichier csv. Cliquez sur l’onglet Données, dans le groupe Données externes, cliquez sur À partir du texte. Sélectionnez votre fichier csv et suivez les instructions de l'assistant d'import.
Avec Google Drive, créez une feuille de calcul. Dans l'onglet Fichier, sélectionnez importer. Suivez les instructions et n'oubliez pas de définir le bon séparateur de colonne (;)

Erreurs fréquentes

Lorsqu'un message d'erreur est remonté, il vous indiquera toujours la ligne où se situe le problème.

1 - Le champ 'NOM_COLONNE' ne doit pas être vide
La colonne désignée contient une ligne vide, alors que la donnée est obligatoire. Vérifiez que toutes les lignes de la colonne concernée soient bien remplies.

2 - Le nombre de colonnes ne correspond pas : 'NOMBRE_TROUVE' au lieu de 'NOMBRE_ATTENDUE'
Le nombre de colonnes de votre fichier ne correspond pas à ce que l'outil d'import attend. Il ne faut surtout pas modifier le nombre de colonne du modèle. Vérifiez le nombre de colonnes de votre fichier. Si tout est bon, vérifiez votre option de séparateur, décrit dans le mode d'emploi.

3 - Le champ 'NOM_DU_CHAMP' ne valide pas le format :
- HH:MM ou MM si vous avez sélectionné 'Temps en minutes' : Lorsque vous renseignez les durées, il y a deux possibilités. Le format HH:MM, n'oubliez pas le séparateur ':' même pour les valeurs nulles. Soit le format MM (ne pas oublier de cocher la case 'Temps en minutes' avant l'import) qui est un simple entier.
Format HH:MM -> 00:00, 01:40, 01:00, 00:30
Format MM -> 0, 100, 60, 30.

- d'une date XX/XX/XXXX : Lorsque vous renseignez une date, celle-ci doit respecter le format JJ/MM/AAAA. Vérifiez la ligne qui pose problème.

4 - UTF8 codec can't decode bytes
Cette erreur survient lorsque les données ne sont pas encodées au format UTF-8. Ouvrez votre fichier CSV et sélectionnez UTF-8 comme encodage de caractères.
Corrigez les données posant des problèmes, à cause des accents dans la plupart des cas. Elles sont facilement identifiables.

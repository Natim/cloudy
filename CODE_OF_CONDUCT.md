# Code of conduct

People who use this repository — issues, changes, and discussion — are expected to be respectful.

- Critique the work. Do not insult the person.
- Harassment and discrimination are not accepted.
- Do not publish other people's private information.
- Report security vulnerabilities in private. See [SECURITY.md](SECURITY.md).

Email [contact@cloudy.fr](mailto:contact@cloudy.fr) if you need to report a problem with someone's conduct. SAS CLOUDY handles those reports.
